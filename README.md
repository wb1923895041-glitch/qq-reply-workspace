# QQ Agent · 本地工作台

Windows 本地 QQ 群助手，提供概览、聊天管理、人格中心、历史、能力和诊断页面。可为多个群分别绑定人格，使用 OneBot v11 反向 WebSocket 处理白名单群里对本账号的文字 @。

**目前仍是开发版，不是 WeChatAgent 的功能等价版本。** 群聊协议链路已使用模拟客户端测试；真实 QQ 客户端、真实群消息和实际发送尚未完成实测。图片、文件、表情、插件、DSH 远程任务、私聊等能力尚未实现。

## 安装和连接

1. 安装 Python 3.10 或以上及 Node.js 22 或以上，双击 `首次安装环境.cmd`。
2. 设置当前用户环境变量 `DEEPSEEK_API_KEY`；不要将密钥写入项目。
3. 双击 `设置连接令牌.cmd`，保存并复制随机令牌。
4. 自行准备并登录支持 OneBot v11 的 QQ 客户端，配置反向 WebSocket 地址 `ws://127.0.0.1:18766/onebot`，令牌填写上一步的值。
5. 双击 `启动QQ工作台.cmd`，在“设置与诊断”填写本人 QQ 号，保持演练模式并保存；在“聊天管理”添加并启用目标群。可在“人格中心”创建人格，并在群配置中选择。
6. 点击概览的“启动服务”，确认通道连接后在目标群发送真正 @ 本账号的文字消息。演练记录只显示在本机；确认实际识别正确后，才可自行关闭演练，以启用发送。

只处理已启用群、配置账号和 OneBot `at` 段指向该账号的纯文字事件。重复消息短期去重，启动前的历史消息不回复；发送超时或接口失败时记录为结果不确定，不自动重发。接口成功代表 QQ 客户端接受请求，不能保证送达或已读。账号与群隔离上下文；演练回复不作为已发送消息加入上下文。切换账号或演练模式前需停止服务。

## 页面与状态

| 页面 | 功能 |
|---|---|
| 概览 | 服务启动停止、连接状态、启用群数 |
| 聊天管理 | 添加、修改、启用、删除群配置，按群选择人格 |
| 人格中心 | 创建、编辑、删除人格；使用中的人格需先解除绑定 |
| 历史记录 | 最近 30 条处理记录和发送状态 |
| 能力与接入 | OneBot 地址与能力状态 |
| 设置与诊断 | QQ 账号、模型、默认人格、演练开关、连接诊断、手动模型预览 |

模型使用 DeepSeek OpenAI 兼容接口；密钥和连接令牌从进程或 Windows 用户环境变量读取。`data/` 保存配置、人格和聊天历史（明文），已被 Git 忽略。消息和上下文会发给模型服务。所有监听仅绑定 127.0.0.1，控制台没有多用户认证，不适合直接暴露到网络。

## 开发和验证

安装 `requirements.txt`，执行 `python -m unittest discover -s tests -v`。项目不包含 QQ 客户端、账号、密钥和私人聊天数据。OneBot 为通信协议，需要用户自行准备兼容客户端；不同客户端可能需要调整配置并实测。

## 实验性平台移植

`qq-platform/` 复用 WeChatAgent 0.4.1 的社交引擎及其依赖，已接入当前工作台的群聊服务；在模拟 OneBot 连接下，群聊识别、人格、模型、预览、发送请求及断线处理已测试。引擎支持的私聊事件尚未接入工作台配置。真实 QQ 收发仍未验证。运行 `node --test qq-platform/tests/*.test.js`。来源与修改见 `qq-platform/vendor/README.md`，上游许可见 `qq-platform/UPSTREAM-LICENSE.txt`。
