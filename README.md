# QQ 回复工作台

Windows 本地 QQ 群聊天助手，包含 OneBot v11 反向 WebSocket 适配、群与账号限定、被 @ 才回复、人格和按账号/群隔离的上下文、历史记录、模型连接和演练模式。

**测试状态：** OneBot 协议链路已用模拟客户端测试；真实 QQ 客户端、真实群消息和实际发送尚未完成实测。当前不提供 WeChatAgent 的 DSH 远程任务、插件、表情、图片与文件功能。

## 安装使用

1. 安装 Python 3.10 或以上，在项目目录双击 `首次安装环境.cmd`。
2. 设置当前用户环境变量 `DEEPSEEK_API_KEY`，无需写入项目。
3. 双击 `设置连接令牌.cmd`，保存并复制随机令牌。
4. 自行安装并登录支持 OneBot v11 的 QQ 客户端，在该客户端设置反向 WebSocket 地址 `ws://127.0.0.1:18766/onebot`、令牌为上一步的值。不要开启无需令牌的公网监听。
5. 双击 `启动QQ工作台.cmd`；填写本人 QQ 号、目标群号、人格，保持“演练模式”开启并保存，再点击“启动服务”。
6. 确认页面显示通道连接，在目标群发送真正 @ 本账号的文字消息；演练记录仅显示在本机，不会发到群里。核对识别后，才可自行关闭演练并保存，以启用发送。

实际发送只适用于已配置账号与群、包含 OneBot `at` 段且目标等于本人 QQ 号的纯文字事件。重复消息被短期去重，启动前的历史消息不回复；发送接口超时或返回失败会停止监听，不自动重发。接口成功只代表 QQ 客户端接受请求，不能保证最终送达或已读。

模型使用 DeepSeek OpenAI 兼容接口；密钥和连接令牌仅从当前进程或 Windows 用户环境变量读取。`data/` 中保存配置和聊天历史（明文），被 Git 忽略。演练消息和上下文会发给模型服务。所有监听仅绑定 127.0.0.1，控制台没有多用户认证，不适合直接暴露到网络。

## 开发

安装 `requirements.txt`，运行 `python -m unittest discover -s tests -v`。项目不包含 QQ 客户端或任何账号、密钥及私人聊天数据。OneBot 是通信协议，需要用户自行准备兼容客户端；客户端不同可能需要调整设置并实测。
