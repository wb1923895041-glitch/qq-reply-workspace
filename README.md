# QQ 回复工作台

一个运行在 Windows 本机的 QQ 群回复工作台。网页界面提供目标群配置、QQ 窗口检测、@ 触发规则和模型回复演练。

> **开发状态：演练版。** 目前不能读取 QQ 消息、自动监听或发送。窗口检测只识别标题，不能确认登录账号。不要将演练结果视为 QQ 接入成功。

## 快速开始

1. 安装 Python 3.10 或更高版本，登录 Windows 版 QQ。
2. 设置用户环境变量 `DEEPSEEK_API_KEY`，无需把密钥写入项目文件。
3. 双击 `启动QQ工作台.cmd`，或运行 `py -3 app.py`，浏览器打开 http://127.0.0.1:18765。
4. 填写群名称和群里被 @ 的昵称并保存，在消息演练中输入 `@昵称 消息内容`。
5. 关闭启动窗口或按 Ctrl+C 停止服务。

配置仅保存在本机 `data/config.json`，Git 默认忽略；密钥从进程或当前用户环境变量读取。演练内容会发送给所配置的 DeepSeek 模型服务，回复不会发往 QQ。

## 开发

仅使用 Python 标准库。运行 `py -3 -m unittest discover -s tests -v`。HTTP 服务只绑定 127.0.0.1，并为写操作设置随机会话令牌。`data/`、缓存和运行截图不纳入版本库。未提供远程访问或多用户认证。

QQ 图形界面的具体适配需要目标客户端和群聊实测，包括识别消息来源、@、群标题及可靠回读。模型密钥属于个人凭据，请勿提交到 GitHub。
